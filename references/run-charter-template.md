# Run charter template

Write this to `<run>/charter.md` before spawning any agent. Every agent reads it first.

```markdown
# COUNCIL CHARTER — <short title> (<date>)

## Question
<The user's question, reframed neutrally in one or two sentences.>
Reader: <who is asking; known profile; unknowns to cover (e.g. "profile unknown: cover
citizen / EU / non-EU / minor / public servant")>.
Reader language: <language>. Today: <date>.
<Prior material: earlier runs, reviews of earlier reports, files the user supplied.>

## Strands / options
<If the question bundles several distinct options or movements, list them (a), (b), (c)…
Agents must not merge them.>

## Quality rules (binding)
Follow references/quality-charter.md. Run-specific points:
1. <e.g. "Neutral on the cause: advice conditional on which demands the reader shares.">
2. <e.g. "Known open conflicts to resolve: …">
3. <Method note: "Web pages cannot be opened in this environment; summaries only → CORROBORATED is the ceiling.">

## Seats
- **<Seat>** — <one-line thinking style>
- …

## Configuration (as approved by the user)
Level: <Level>. Research: <…>. Debate: <…>. Fact desk: <…>. Audit: <…>.
```
